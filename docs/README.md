首版完成定义：真实 Qwen 对话 + 持久化 Agent 任务 + 证照申请填单/草稿/提交 + 本人待办筛选/确认/代审核 + 可追溯异常恢复。模拟的是企业外部业务系统，模型、数据库及实际状态变化需要真实运行。

开发前技术验证：锁定框架兼容版本；验证 Qwen 流式工具调用、LangGraph4j PostgreSQL Checkpoint、跨请求暂停恢复。验证结果记录到版本清单，未验证前不声明示例代码可直接编译。
